# Windows без Docker

Windows-приложение запускает встроенный `livekit-server.exe` v1.13.8 напрямую и одновременно работает как сервер и клиент просмотра. Docker Desktop, WSL2, Node.js и отдельная установка LiveKit на пользовательском ПК не нужны. VPN и Android-приложение сохраняют прежнюю схему подключения одним кодом USCV1.

## Установка

1. Скачайте новый EXE из GitHub Actions, распакуйте ZIP и установите приложение. Если использовалась старая версия с Docker, сначала остановите её сервер; старый контейнер не должен занимать порты.
2. Для VPN установите официальный WireGuard для Windows, настройте ретранслятор в приложении и нажмите «Включить VPN на Windows». Для локального испытания можно выбрать LAN.
3. Нажмите «Проверить готовность Windows»: встроенный LiveKit должен быть найден, порты TCP 3100/7880/7881 и UDP 7882 свободны.
4. Нажмите «Запустить сервер и просмотр», создайте комнату и код оператора. В Android APK WireGuard уже встроен.
5. Вставьте код USCV1 в Android-приложение, разрешите VPN и захват экрана. В Windows откройте комнату для просмотра.

При остановке сервера или выходе из приложения завершается его процесс LiveKit. После аварийного завершения приложения кнопка восстановления завершает только процесс с точным путём встроенного EXE и конфигурацией текущего профиля. Чужие LiveKit-процессы не останавливаются. Комнаты и VPN-настройки сохраняются.

Для VPN требуется доступный Linux-ретранслятор и правила Windows Firewall, ограничивающие доступ к портам доверенной VPN-подсетью. Настройка брандмауэра: windows/setup-firewall.ps1. Проверка на физических пультах по-прежнему необходима.

## Сборка из исходников

Только разработчику нужны Node.js 22+ и инструменты npm. Из корня проекта:

```powershell
./scripts/prepare-livekit.ps1
./RUN_TESTS.ps1
node scripts/native-livekit-smoke.cjs
cd windows
npm ci
npm run dist:win
```

Скрипт подготовки скачивает официальный архив LiveKit с GitHub и проверяет закреплённый SHA256. EXE и LICENSE включаются в resources/livekit установщика. Нативный интеграционный тест проверяет запуск, авторизованные операции комнат LiveKit, API приложения, остановку, повторный запуск, освобождение портов и восстановление процесса. В GitHub Actions всё выполняется автоматически.

Старые compose-config/server-recovery функции сохранены для истории и тестов совместимости. Рабочее Windows-приложение не вызывает Docker.
