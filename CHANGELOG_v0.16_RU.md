# Windows v0.16 — общая видеостена ФПВ-пультов

- Кнопка «Все пульты» показывает видеопотоки из всех комнат одновременно. Потоки одной комнаты по-прежнему можно смотреть отдельно.
- Каждая плитка подписана комнатой и именем оператора. Идентификаторы потоков включают комнату, поэтому одинаковые имена не смешивают видео.
- Сетка: авто или 1, 2, 3, 4 столбца; выбор сохраняется. На небольшом экране используется не более двух столбцов.
- «Крупно» увеличивает выбранный поток; повторное нажатие возвращает сетку. Кнопка «Во весь экран» разворачивает видеостену, Esc возвращает обычный режим. Двойной щелчок по видео разворачивает отдельный поток.
- Статус подключения отображается отдельно для каждой комнаты; при восстановлении связи меняется и индикатор соответствующих плиток.
- Независимое переподключение комнат с задержкой от 1 до 15 секунд. Отказ одной комнаты не прерывает другие. При переключении режима отменяются ожидающие подключения и повторы.
- Кнопка «Обновить» подключает новые комнаты и отключает удалённые, сохраняя остальные соединения.
- Создание/отзыв ключей остаются внутри выбранной комнаты. В общей видеостене эти действия скрыты или недоступны, чтобы не выдать ключ не в ту комнату.
- Видеосервер остаётся встроенным нативным LiveKit. Docker и WSL2 не нужны.

## Как пользоваться

1. Установить Windows EXE версии 0.16.0. Настроенные комнаты и VPN-параметры сохраняются.
2. Запустить сервер. Подключить Android-пульты обычными кодами USCV1.
3. Нажать «Все пульты» слева. При необходимости выбрать сетку и развернуть видеостену.
4. Для управления ключами нажать конкретную комнату слева.

Android APK v0.15 совместим с этим обновлением; его переустановка не требуется. Это просмотр экранов пультов, а не управление полётом.

## Проверки

71 автоматический Node-тест, включая изоляцию обрывов между комнатами, отмену запоздавших соединений, добавление/удаление комнат и одинаковые идентификаторы участников.

Тест Electron smoke: настоящий нативный LiveKit, две разные комнаты, два синтетических canvas-видеопотока, декодирование кадров обоих видео, увеличение/возврат сетки, отключение одного источника с сохранением второго и переход обратно в отдельную комнату. Тест добавлен в GitHub Actions.

Физические ФПВ-пульты и предельное число одновременных потоков в этой проверке не использовались. Фактическая ёмкость зависит от CPU/GPU Windows, качества потоков и сети.
