# Windows v0.49 / Android v0.32

Сохранены назначения комнат и настройки v0.48. Для новых ключей на обновлённом ретрансляторе добавлен WireGuard через WSS/HTTPS (TCP 443): зашифрованные пакеты WireGuard передаются внутри TLS. Это помогает в сетях, где прямой UDP недоступен. Старые коды продолжают использовать UDP; новые коды с транспортом требуют APK v0.32. Каждый оператор получает отдельный транспортный секрет; VPS хранит его SHA256, отзыв VPN-пира закрывает транспорт. Административный секрет VPS в APK не передаётся. При разрыве транспорта текущий сеанс нужно запустить заново.

В конфигурациях новых туннелей указан MTU 1280 для совместимости с вложенными VPN. На существующих Windows-туннелях нужно отдельно обновить конфигурацию; обновление программы не перезапускает пользовательский VPN.

Корректный код USCV1 теперь сохраняется через Android Keystore сразу после проверки структуры, даже если сеть или Windows сейчас недоступны. Отмена системного разрешения VPN не удаляет сохранённый код. LAN-ключ сохраняется после успешного подключения.

Установка обновлённого VPS требует `npm ci --prefix relay`; установщик выполняет это автоматически. Для нестандартного UDP-порта задайте `USC_WG_PORT` в защищённом файле окружения службы: WSS направляет пакеты только в локальный WireGuard. Исходный UDP остаётся доступен. Docker не используется.
