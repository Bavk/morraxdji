Оба файла скачаны, SHA256 совпали с SHA256SUMS.txt. APK содержит libwg-go.so для arm64-v8a, armeabi-v7a, x86 и x86_64. Журнал Android подтверждает testDebugUnitTest и BUILD SUCCESSFUL. Android-код остаётся версии 0.29.0; APK на физический пульт не устанавливался.

Локально прошли 163 модульных теста, сборка интерфейса, smoke:ui и smoke:wall. Electron проверяет естественный порядок имён двух записей, фильтры доступности и продолжение воспроизведения после изменения сортировки. Модульные тесты проверяют недоступные файлы, сочетание с поиском, порядок дат и размеров, отсутствие изменения исходного списка и некорректные метаданные. Сценарий Electron не перемещает и не удаляет реальные пользовательские файлы.

Windows Actions содержит USC_ELECTRON_SMOKE_PASS, USC_WALL_SMOKE_PASS и подтверждение публикации установщика. На момент отчёта сводный API Actions показывает queued вопреки готовым артефактам и завершённым журналам; агрегированный успешный статус не подтверждён.

При закрытом приложении EXE установлен с кодом 0. В установленном app.asar проверены версия 0.40.0, новые элементы архива, прежние модули записи, событий, питания, кодов подключения и встроенный LiveKit.

Использовались синтетические видеопотоки. Реальные пульты, VPN и длительная нагрузка требуют испытаний на оборудовании. Пользовательские ключи и профили не читались и не публиковались. Docker и WSL2 не требуются; для VPN Windows нужен WireGuard.

EXE без подписи издателя, APK с debug-подписью. Артефакты GitHub хранятся 30 дней; для скачивания может потребоваться вход.
