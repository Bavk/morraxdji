# Universal Stream Control — изменения v0.7

- Windows: обновляемая сетка видеотрансляций, режим фокуса, возобновление просмотра при окончательном разрыве связи.
- Windows: в модуле `viewer-reconnect.mjs` нарастающие интервалы переподключения, отмена после выбора другой комнаты; unit-тесты.
- Android: профили экономии, стандарта и детализации, настройки в локальном хранилище, ограничение максимального битрейта.
- Android: быстрый отказ при неверных ключах HTTP 4xx, повторы при временных сетевых ошибках, защита от устаревших ответов после остановки трансляции.
- Исходные операторские ключи `USCV1`, VPN-конфигурация ретранслятора, API и данные комнат остаются без изменений.

## Известные ограничения

Прототип не проходил испытания реального Android-пульта, Win/Docker, VPN и WebRTC. Публикация исходников НЕ означает готовый EXE/APK и не гарантирует конкретные FPS или число зрителей. Для установки Android SDK, Docker и Windows WireGuard требуются отдельные средства и права администратора.
