# Результаты сборки v0.43

Исходники: `b877b6f8b422a62d2213b0c98bbe8c6523ecf362`. [Запуск GitHub Actions](https://github.com/Bavk/morraxdji/actions/runs/39801504027).

- [Android APK v0.29.0 со встроенным WireGuard](https://github.com/Bavk/morraxdji/actions/runs/39801504027/artifacts/12435847311)

EXE: 100578664 байта, SHA256 `27498da67e872673d6e05eb6d0a00e8c05fdc985f3ef93288ae4da77bbbb3777`.

APK: 73311213 байт, SHA256 `2f026001f0a72d966cdcf16658bf6595dab0e1630d48c233e141d9748ed239d7`.

Файлы скачаны и сверены с SHA256SUMS.txt. В APK подтверждены libwg-go.so для arm64-v8a, armeabi-v7a, x86 и x86_64. Журнал Android содержит testDebugUnitTest и BUILD SUCCESSFUL. Android-код остался версии 0.29.0; APK на пульт не устанавливался.

Локально и в GitHub прошли 184 модульных теста, проверки структуры исходников и preflight репозитория. Новые восемь тестов охватывают все сочетания количества источников 1–16 и столбцов авто/1–4 в пределах размеров PNG, отсутствие скрытых источников и сохранённый порядок, пропорции портретного/широкого кадра, подписи состояния и времени, отсутствие кадров, сокращение текста, отказ при превышении лимитов и освобождение canvas после ошибки.

Локально прошли build:ui, smoke:ui и smoke:wall. Windows Actions содержит USC_ELECTRON_SMOKE_PASS и USC_WALL_SMOKE_PASS с общим PNG двух источников (1324×512), PNG одного видимого источника при увеличении (672×512), блокировкой кнопки при пустом поиске, отменой и ожиданием сохранения при закрытии. Изображения декодируются настоящим Electron nativeImage. Локальный общий PNG визуально проверен: подписи читаемы, один остановившийся источник отмечен «Нет новых кадров», другой — LIVE. Прежние сценарии видеостены, записи, архива, заметок, сигналов, питания и ключей сохранены.

EXE установлен при закрытом приложении, код установщика 0. В установленном app.asar проверены версия 0.43.0, новый интерфейс снимка, прежние модули и встроенный LiveKit. Принудительного закрытия пользовательского приложения не было.

На момент отчёта сводный API Actions продолжает показывать in_progress вопреки завершённым журналам и опубликованным артефактам; агрегированный успешный статус не подтверждён.

Общий снимок масштабирует изображения в области 640×360, не синхронизирует время кадров разных пультов и содержит местное время Windows-ПК. Отдельная кнопка «Кадр» сохраняет исходное разрешение. Не более 16 видимых источников; при превышении лимита снимок не создаётся, источники молча не отбрасываются.

Использовались синтетические источники и временные тестовые файлы. Реальные пульты, VPN и длительная нагрузка отдельно не испытывались. Пользовательские VPN-ключи и профили не читались и не публиковались. Docker и WSL2 не требуются; для VPN Windows нужен WireGuard.

EXE без подписи издателя, APK с debug-подписью. Артефакты хранятся 30 дней; для скачивания может потребоваться вход в GitHub.
