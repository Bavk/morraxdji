# Результаты сборки v0.41

Исходники: `073f77f9d319f56b901a019fa955904b981cf947`. [Запуск GitHub Actions](https://github.com/Bavk/morraxdji/actions/runs/39797933132).

- [Windows EXE v0.41.0](https://github.com/Bavk/morraxdji/actions/runs/39797933132/artifacts/12434053000)
- [Android APK v0.29.0 со встроенным WireGuard](https://github.com/Bavk/morraxdji/actions/runs/39797933132/artifacts/12433204735)

EXE: 100576446 байт, SHA256 `6434aee958e5d888c4645ed191b0eb271278ba808e1ff2f99f6d4f3a6679ec32`.

APK: 73311213 байт, SHA256 `c80df9adc407abe9a84e39f13153f719116b016f9df3e40363f0ec14a1ff4551`.

Оба файла скачаны и сверены с SHA256SUMS.txt. APK содержит libwg-go.so для arm64-v8a, armeabi-v7a, x86 и x86_64. Журнал Android подтверждает testDebugUnitTest и BUILD SUCCESSFUL. Android-код не менялся, версия 0.29.0 совместима; APK на физический пульт не устанавливался.

Локально прошли 170 модульных тестов, сборка интерфейса, smoke:ui и smoke:wall. Семь новых модульных тестов проверяют включение по запросу пользователя, необходимость ранее обновлявшегося видео, объединение сигналов интервалом десять секунд, восстановление, паузу и удаление источников, выключение, ошибки выхода, ограниченный тон и освобождение контекста, отмену позднего включения и suspended-контекст.

Windows Actions содержит USC_ELECTRON_SMOKE_PASS и USC_WALL_SMOKE_PASS с новым сценарием: сигнал выключен по умолчанию, включается, тестовая кнопка вызывает тон, остановка кадров синтетического источника вызывает один дополнительный тон, выключение блокирует кнопку проверки. Аудиовыход подменён, реальный звук при тестировании не воспроизводился. Прежние сценарии потоков, записи, архива, PNG и управления пультами сохранены. Политика ручной/адаптивной паузы дополнительно проверена модульно. Перед окончательной CI-сборкой элементы звука перенесены в панель поиска, чтобы не перегружать заголовок; CI проверил итоговую разметку.

EXE установлен при закрытом приложении; код установщика 0. В установленном app.asar проверены версия 0.41.0, новые элементы звука, прежние модули и встроенный LiveKit. Приложение пользователя принудительно не закрывалось.

На момент отчёта сводный API Actions показывает queued вопреки готовым артефактам и завершённым журналам; агрегированный успешный статус не подтверждён.

Реальная слышимость на устройствах вывода, аппаратные пульты, VPN и длительная нагрузка отдельно не испытывались. Использовались синтетические потоки. Пользовательские ключи и профили не читались и не публиковались. Docker и WSL2 не требуются; для VPN Windows нужен WireGuard.

EXE без подписи издателя, APK с debug-подписью. Артефакты хранятся 30 дней; для скачивания может потребоваться вход в GitHub.
