# Universal Stream Control v0.12 — 22.10.2026

## Назначение
Windows остаётся одновременно сервером LiveKit и клиентом просмотра. Android APK захватывает экран и отправляет поток через встроенный WireGuard. VPN-ретранслятор может потребоваться при разных провайдерах/CG-NAT, но основной видеосервер расположен на Windows.

## Исправления

1. **Безопасное удаление комнат при сбое LiveKit.** Сервер сначала удаляет комнату и её ключи из локальной базы (новые операторские сеансы блокируются), затем пробует закрыть комнату в LiveKit. При ошибке сохраняется операция для повторного исполнения. Удаление не превращается в ответ HTTP 500 после фактической локальной блокировки.
2. **Защита от уже выданных LiveKit JWT.** При удалении комнаты создаётся запись, сохраняемая минимум на 6 минут (5 минут срока JWT + 1 минута запаса). Во время этого окна LiveKit периодически получает повторную команду закрытия комнаты, даже если она уже была закрыта. Это ограничивает повторные подключения со старыми токенами. Запись удаляется только после окончания защитного периода и успешной команды LiveKit.
3. **Восстановление после перезапуска.** Ожидающие удаления записаны в `rooms.json` и сохраняются после закрытия или падения приложения Windows.
4. **VPN-пиры из удалённых комнат.** Очистка на Windows теперь определяет осиротевшие пиры сравнением всех локально зарегистрированных VPN-пиров с активными ключами всех оставшихся комнат. Это позволяет удалить пир после удаления комнаты даже при недоступном на момент удаления VPS.
5. **Интерфейс Windows.** Предупреждения о неполной очистке не теряются; отображается число удалённых комнат, для которых действует защита от старых токенов. Команда ручной сверки отображает и ошибки удаления комнат.
6. **Совместимость данных.** Базы `rooms.json` от v0.11 (без поля `pendingRoomDeletes`) автоматически читаются без сброса комнат. Android-коды `USCV1` не изменены.

## Проверено
- 53/53 автоматических Node.js теста, включая сценарий: создать комнату, выдать ключ, выключить LiveKit, удалить комнату, проверить запрет нового токена, перезапустить API, повторить удаление LiveKit, снять защиту после истечения срока.
- JavaScript `node --check`, проверка сборочной структуры, Bash `bash -n` и разбор Android XML выполнены.
- 7 автономных Kotlin-проверок качества видеопотока.

## Не проверено
- Сборка Android APK и Windows EXE (не доступны необходимые внешние зависимости/полная среда сборки).
- Реальный захват экрана Android, WireGuard на Windows и Android, Docker Desktop, работа с физическими пультами, поток через мобильную сеть.
- Пропускная способность, задержка и число одновременно работающих операторов.

Важно: этот релиз является исходным прототипом для дальнейших испытаний, а не прошедшим приёмку установщиком.
