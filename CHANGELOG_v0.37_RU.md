# Windows v0.37 — ограниченное хранение кода в буфере обмена

Кнопка «Скопировать код» в окне выдачи оператора теперь копирует USCV1 или LAN-ключ через основной процесс Electron. Программа проверяет формат и запускает таймер на 60 секунд. По истечении времени буфер очищается, только если его текст всё ещё точно совпадает со скопированным кодом. Другой текст, скопированный позже, сохраняется.

Повторное копирование, включая тот же код, начинает новый полный интервал. При штатном выходе выполняется такая же условная очистка. Закрытие окна выдачи кода не отменяет таймер. Ошибка копирования показывается явно; прежний обходной путь через execCommand удалён, чтобы не создавать копию без таймера.

Если системный буфер недоступен при очистке, программа не завершается аварийно. Очистка не гарантируется после аварии или принудительного завершения приложения. Она не удаляет историю буфера Windows, синхронизированные копии, файлы `.usc` и данные в других приложениях. Если пользователь снова скопировал точно тот же текст из другого источника, по текстовому совпадению он тоже может быть очищен.

Настройка касается только кнопки копирования операторского кода. Копирование адреса сервера остаётся обычным. Таймер и код не записываются на диск и не публикуются. Формат подключения, VPN и права доступа не меняются.

Windows имеет версию 0.37.0. Android APK v0.29 со встроенным WireGuard совместим и собирается заново без изменения Android-кода. Исходники и прежние функции сохранены. Docker и WSL2 не требуются.

## Проверки

155 Node-тестов. Новые проверки охватывают очистку по таймеру, сохранение чужого текста, замену таймера при новом/повторном коде, устаревшие callbacks, проверку формата, условную очистку при выходе и ошибку чтения буфера.

В Electron проверяются копирование синтетического USCV1-кода через интерфейс/IPC, выполнение таймера и сохранение другого текста. Для этого используется отдельный подставной буфер: реальный пользовательский буфер тест не читает и не меняет. Прежние сценарии видеостены и записи сохранены.

Фактическое поведение системного буфера Windows и его истории требует отдельной пользовательской проверки. Реальные пульты, VPN и длительная нагрузка также требуют испытаний на оборудовании.
