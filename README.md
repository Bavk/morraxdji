## Готовые сборки

GitHub Actions успешно собрал обе платформы: [запуск 39785111844](https://github.com/Bavk/morraxdji/actions/runs/39785111844).

- [Windows EXE — NSIS установщик](https://github.com/Bavk/morraxdji/actions/runs/39785111844/artifacts/12428787110)
- [Android APK со встроенным WireGuard](https://github.com/Bavk/morraxdji/actions/runs/39785111844/artifacts/12429040755)

Артефакты скачиваются как ZIP вместе с SHA256SUMS.txt; для скачивания может потребоваться вход в GitHub. Срок хранения — 30 дней. Новая сборка запускается при push в main или вручную через Actions.

EXE без цифровой подписи, APK подписан отладочным ключом. Windows одновременно запускает локальный видеосервер и просмотр; LiveKit встроен в EXE и работает без Docker/WSL2; для VPN нужен WireGuard для Windows. Для подключения через интернет требуется настроенный VPN-ретранслятор. На Android WireGuard встроен в APK, отдельное приложение не требуется.

Проверены 140 автоматических тестов, запуск интерфейса Electron, упаковка серверных модулей, формат EXE, пакет и подпись APK, контрольные суммы и наличие нативных библиотек WireGuard для четырёх архитектур. Перед эксплуатацией требуется испытание трансляции и VPN на реальных пультах: [результаты сборки](BUILD_RESULTS_v0.32.md).

**Windows без Docker:** [актуальная инструкция](WINDOWS_NATIVE_RU.md). При сборке запускается настоящий встроенный LiveKit и проверяются операции комнат, остановка и перезапуск.

## Несколько ФПВ-пультов одновременно

В Windows v0.16 нажмите **«Все пульты»** для просмотра потоков из всех комнат. Доступны сетка авто/1–4 столбца, увеличение выбранного видео, полноэкранная видеостена и независимое переподключение каждой комнаты. Управление ключами находится внутри выбранной комнаты. Android APK v0.15 совместим и не требует переустановки.

[Все изменения и инструкция v0.16](CHANGELOG_v0.16_RU.md). На настоящем Electron проверены два одновременно декодируемых тестовых потока; нагрузка на физических пультах проверяется отдельно.

## Контроль видео v0.17

Под каждым потоком отображаются разрешение, FPS, входящий битрейт и потери пакетов. Если четыре секунды нет новых кадров, плитка выделяется и показывает возраст кадра; при возобновлении видео предупреждение снимается автоматически. RTT сервера обозначен отдельно и не является полной задержкой видео с пульта. [Изменения v0.17](CHANGELOG_v0.17_RU.md).

## Запись потоков v0.18

Нажмите **«● Запись»** на нужной плитке и выберите новый файл WebM. Можно записывать до четырёх пультов независимо и без звука. Красная кнопка с таймером останавливает запись. При отключении источника, смене комнаты или закрытии окна файл завершается автоматически. Запись скрытой увеличением другого видео плитки продолжается. [Инструкция v0.18](CHANGELOG_v0.18_RU.md).

## Архив записей v0.19

Кнопка **«Архив записей»** доступна со стартового экрана и боковой панели сервера. Новые видео добавляются автоматически; старые WebM можно добавить вручную. Есть поиск, дата и размер, встроенное воспроизведение и показ в проводнике. «Убрать» удаляет только строку из списка, сохраняя файл. [Инструкция v0.19](CHANGELOG_v0.19_RU.md).

## Снимок кадра v0.20

Кнопка **«Кадр»** на видеоплитке сохраняет PNG в разрешении принимаемого видео, без кнопок и статистики Windows. Фиксируется изображение до выбора папки; существующий файл не перезаписывается. Для остановившегося видео уведомление указывает, что сохранён последний доступный кадр. [Инструкция v0.20](CHANGELOG_v0.20_RU.md).

## Журнал событий v0.21

Кнопка **«Журнал событий»** открывает историю начала просмотра, отключений пультов, остановки и восстановления кадров, соединений с комнатами. Доступны поиск и экспорт всего журнала в JSON. Последние 2000 событий сохраняются локально и доступны при остановленном сервере. [Инструкция v0.21](CHANGELOG_v0.21_RU.md).

## Порядок пультов v0.22

Кнопка **«Порядок пультов»** позволяет переставлять источники стрелками. Порядок и число столбцов сохраняются локально и восстанавливаются после перезапуска и переподключения. Перестановка не останавливает текущие записи. Кнопка «По подключению» сбрасывает порядок. [Инструкция v0.22](CHANGELOG_v0.22_RU.md).

## Пауза приёма v0.23

Кнопка **«Пауза»** отключает доставку видео выбранного пульта текущему Windows-зрителю, сохраняя остальные потоки. «Приём» возобновляет просмотр без переподключения. При активной записи пауза недоступна; на паузе отключены запись и снимок. Последний кадр явно обозначен как не обновляющийся. [Инструкция v0.23](CHANGELOG_v0.23_RU.md).

## Поиск пультов v0.24

Поле **«Найти пульт»** фильтрует открытые видеопотоки по имени и комнате. Есть счётчик результатов, очистка кнопкой или Escape и подсказка при отсутствии совпадений. Скрытые записи продолжаются; их число указано отдельно. [Инструкция v0.24](CHANGELOG_v0.24_RU.md).

## Активные записи v0.25

Кнопка **«Записи: N»** открывает все текущие записи, включая скрытые поиском. Можно перейти к пульту, завершить одну запись или сохранить все с подтверждением. Панель показывает время, путь файла и состояние сохранения. [Инструкция v0.25](CHANGELOG_v0.25_RU.md).

## Проверка места v0.26

Перед записью проверяется выбранный диск: ниже 256 МиБ запись не начинается, ниже 1 ГиБ требуется подтверждение предупреждения. В панели записей отображается свободный объём при запуске; место не резервируется. [Инструкция v0.26](CHANGELOG_v0.26_RU.md).

## Защита экрана v0.27

Настройка **«Не выключать экран при работающем сервере»** сохраняется локально. Программа удерживает запрос на блокировку автоматического сна экрана только во время работы сервера и снимает его при остановке или выходе. Схемы питания Windows не меняются. [Инструкция v0.27](CHANGELOG_v0.27_RU.md).

## Перенос кода v0.28

Windows сохраняет новый VPN-код в файл **`.usc`**, Android загружает его кнопкой **«Загрузить код из файла»** через системный диалог. Камера не требуется. Файл содержит секреты подключения: не публикуйте его и передавайте только нужному оператору. Импорт не запускает VPN автоматически. [Инструкция v0.28](CHANGELOG_v0.28_RU.md).

## Очистка подключения v0.29

Android позволяет **удалить сохранённое подключение** после подтверждения, когда трансляция и VPN остановлены. Удаляются локальный шифротекст и ключ Android Keystore; код на Windows остаётся действующим до отдельного отзыва. Файлы `.usc` и буфер обмена не очищаются. [Инструкция v0.29](CHANGELOG_v0.29_RU.md).

## Защита записей v0.30

При смене комнаты или переходе на общую видеостену с активными записями требуется подтверждение. Отмена сохраняет текущий просмотр и запись. Повторный выбор уже открытой видеостены больше не пересоздаёт соединения и не завершает записи. [Инструкция v0.30](CHANGELOG_v0.30_RU.md).

## Завершение записи v0.31

Исправлена блокировка кнопок после сохранения или ошибки видеозаписи: состояние рекордера завершается до обновления интерфейса. Пауза приёма и новая запись снова доступны без смены раскладки; счётчик скрытых записей обновляется сразу. [Подробности v0.31](CHANGELOG_v0.31_RU.md).

## Горячие клавиши v0.32

Клавиши **1–9** открывают пульт крупно в текущем порядке с учётом поиска; **Escape** возвращает сетку. Первые девять результатов отмечены номерами. Ввод текста, открытые диалоги и полноэкранный режим блокируют горячие клавиши. Записи продолжаются. [Инструкция v0.32](CHANGELOG_v0.32_RU.md).
