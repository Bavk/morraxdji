## Готовые сборки

GitHub Actions успешно собрал обе платформы: [запуск 39770839803](https://github.com/Bavk/morraxdji/actions/runs/39770839803).

- [Windows EXE — NSIS установщик](https://github.com/Bavk/morraxdji/actions/runs/39770839803/artifacts/12421688270)
- [Android APK со встроенным WireGuard](https://github.com/Bavk/morraxdji/actions/runs/39770839803/artifacts/12421548898)

Артефакты скачиваются как ZIP вместе с SHA256SUMS.txt; для скачивания может потребоваться вход в GitHub. Срок хранения — 30 дней. Новая сборка запускается при push в main или вручную через Actions.

EXE без цифровой подписи, APK подписан отладочным ключом. Windows одновременно запускает локальный видеосервер и просмотр; LiveKit встроен в EXE и работает без Docker/WSL2; для VPN нужен WireGuard для Windows. Для подключения через интернет требуется настроенный VPN-ретранслятор. На Android WireGuard встроен в APK, отдельное приложение не требуется.

Проверены 97 автоматических тестов, запуск интерфейса Electron, упаковка серверных модулей, формат EXE, пакет и подпись APK, контрольные суммы и наличие нативных библиотек WireGuard для четырёх архитектур. Перед эксплуатацией требуется испытание трансляции и VPN на реальных пультах: [результаты сборки](BUILD_RESULTS_v0.19.md).

**Windows без Docker:** [актуальная инструкция](WINDOWS_NATIVE_RU.md). При сборке запускается настоящий встроенный LiveKit и проверяются операции комнат, остановка и перезапуск.

## Несколько ФПВ-пультов одновременно

В Windows v0.16 нажмите **«Все пульты»** для просмотра потоков из всех комнат. Доступны сетка авто/1–4 столбца, увеличение выбранного видео, полноэкранная видеостена и независимое переподключение каждой комнаты. Управление ключами находится внутри выбранной комнаты. Android APK v0.15 совместим и не требует переустановки.

[Все изменения и инструкция v0.16](CHANGELOG_v0.16_RU.md). На настоящем Electron проверены два одновременно декодируемых тестовых потока; нагрузка на физических пультах проверяется отдельно.

## Контроль видео v0.17

Под каждым потоком отображаются разрешение, FPS, входящий битрейт и потери пакетов. Если четыре секунды нет новых кадров, плитка выделяется и показывает возраст кадра; при возобновлении видео предупреждение снимается автоматически. RTT сервера обозначен отдельно и не является полной задержкой видео с пульта. [Изменения v0.17](CHANGELOG_v0.17_RU.md).

## Запись потоков v0.18

Нажмите **«● Запись»** на нужной плитке и выберите новый файл WebM. Можно записывать до четырёх пультов независимо и без звука. Красная кнопка с таймером останавливает запись. При отключении источника, смене комнаты или закрытии окна файл завершается автоматически. Запись скрытой увеличением другого видео плитки продолжается. [Инструкция v0.18](CHANGELOG_v0.18_RU.md).

## Архив записей v0.19

Кнопка **«Архив записей»** доступна со стартового экрана и боковой панели сервера. Новые видео добавляются автоматически; старые WebM можно добавить вручную. Есть поиск, дата и размер, встроенное воспроизведение и показ в проводнике. «Убрать» удаляет только строку из списка, сохраняя файл. [Инструкция v0.19](CHANGELOG_v0.19_RU.md).
