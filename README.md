# Universal Stream Control — Windows v0.49 / Android v0.32


**Обновление v0.49 / APK v0.32:** назначения доступных комнат операторам, выбор комнаты на Android, настройки просмотра, зашифрованное сохранение ключа и WireGuard через HTTPS/WSS. [Результаты и готовые EXE/APK](BUILD_RESULTS_v0.49.md). [Изменения управления комнатами](CHANGELOG_v0.48_RU.md), [изменения VPN и сохранения кода](CHANGELOG_v0.49_RU.md).

**Русская документация:** [README_RU.md](README_RU.md).

**Сборка EXE и APK через GitHub Actions:** [GITHUB_START_RU.md](GITHUB_START_RU.md).

**Первое испытание на оборудовании:** [FIRST_REAL_RUN_RU.md](FIRST_REAL_RUN_RU.md).

## Готовые сборки

EXE и APK собраны; GitHub Actions завершился успешно: [запуск 39831722482](https://github.com/Bavk/morraxdji/actions/runs/39831722482).

- [Windows EXE — NSIS установщик](https://github.com/Bavk/morraxdji/actions/runs/39831722482/artifacts/12448763037)
- [Android APK со встроенным WireGuard](https://github.com/Bavk/morraxdji/actions/runs/39831722482/artifacts/12449211627)

Артефакты скачиваются как ZIP вместе с SHA256SUMS.txt; для скачивания может потребоваться вход в GitHub. Срок хранения — 30 дней. Новая сборка запускается при push в main или вручную через Actions.

EXE без цифровой подписи, APK подписан отладочным ключом. Windows одновременно запускает локальный видеосервер и просмотр; LiveKit встроен в EXE и работает без Docker/WSL2; для VPN нужен WireGuard для Windows. Для подключения через интернет требуется настроенный VPN-ретранслятор. На Android WireGuard встроен в APK, отдельное приложение не требуется.

Проверены 215 автоматических тестов, запуск интерфейса Electron, упаковка серверных модулей, формат EXE, пакет и подпись APK, контрольные суммы и наличие нативных библиотек WireGuard для четырёх архитектур. На DJI RC Plus 2 проверены VPN/WSS, передача экрана и сохранение ключа; испытания других моделей и длительной нагрузки ещё нужны: [результаты сборки](BUILD_RESULTS_v0.49.md).

**Windows без Docker:** [актуальная инструкция](WINDOWS_NATIVE_RU.md). При сборке запускается настоящий встроенный LiveKit и проверяются операции комнат, остановка и перезапуск.

## Несколько ФПВ-пультов одновременно

В Windows v0.16 нажмите **«Все пульты»** для просмотра потоков из всех комнат. Доступны сетка авто/1–4 столбца, увеличение выбранного видео, полноэкранная видеостена и независимое переподключение каждой комнаты. Управление ключами находится внутри выбранной комнаты. Android APK v0.15 совместим и не требует переустановки.

[Все изменения и инструкция v0.16](CHANGELOG_v0.16_RU.md). На настоящем Electron проверены два одновременно декодируемых тестовых потока; нагрузка на физических пультах проверяется отдельно.

## Контроль видео v0.17

Под каждым потоком отображаются разрешение, FPS, входящий битрейт и потери пакетов. Если четыре секунды нет новых кадров, плитка выделяется и показывает возраст кадра; при возобновлении видео предупреждение снимается автоматически. RTT сервера обозначен отдельно и не является полной задержкой видео с пульта. [Изменения v0.17](CHANGELOG_v0.17_RU.md).

## Запись потоков v0.18

Нажмите **«● Запись»** на нужной плитке и выберите новый файл WebM. Можно записывать до четырёх пультов независимо и без звука. Красная кнопка с таймером останавливает запись. При отключении источника, смене комнаты или закрытии окна файл завершается автоматически. Запись скрытой увеличением другого видео плитки продолжается. [Инструкция v0.18](CHANGELOG_v0.18_RU.md).

## Архив записей v0.19

Кнопка **«Архив записей»** доступна со стартового экрана и боковой панели сервера. Новые видео добавляются автоматически; старые WebM можно добавить вручную. Есть поиск, дата и размер, встроенное воспроизведение и показ в проводнике. «Убрать» удаляет только строку из списка, сохраняя файл. [Инструкция v0.19](CHANGELOG_v0.19_RU.md).

## Снимок кадра v0.20

Кнопка **«Кадр»** на видеоплитке сохраняет PNG в разрешении принимаемого видео, без кнопок и статистики Windows. Фиксируется изображение до выбора папки; существующий файл не перезаписывается. Для остановившегося видео уведомление указывает, что сохранён последний доступный кадр. [Инструкция v0.20](CHANGELOG_v0.20_RU.md).

## Журнал событий v0.21

Кнопка **«Журнал событий»** открывает историю начала просмотра, отключений пультов, остановки и восстановления кадров, соединений с комнатами. Доступны поиск и экспорт всего журнала в JSON. Последние 2000 событий сохраняются локально и доступны при остановленном сервере. [Инструкция v0.21](CHANGELOG_v0.21_RU.md).

## Порядок пультов v0.22

Кнопка **«Порядок пультов»** позволяет переставлять источники стрелками. Порядок и число столбцов сохраняются локально и восстанавливаются после перезапуска и переподключения. Перестановка не останавливает текущие записи. Кнопка «По подключению» сбрасывает порядок. [Инструкция v0.22](CHANGELOG_v0.22_RU.md).

## Пауза приёма v0.23

Кнопка **«Пауза»** отключает доставку видео выбранного пульта текущему Windows-зрителю, сохраняя остальные потоки. «Приём» возобновляет просмотр без переподключения. При активной записи пауза недоступна; на паузе отключены запись и снимок. Последний кадр явно обозначен как не обновляющийся. [Инструкция v0.23](CHANGELOG_v0.23_RU.md).

## Поиск пультов v0.24

Поле **«Найти пульт»** фильтрует открытые видеопотоки по имени и комнате. Есть счётчик результатов, очистка кнопкой или Escape и подсказка при отсутствии совпадений. Скрытые записи продолжаются; их число указано отдельно. [Инструкция v0.24](CHANGELOG_v0.24_RU.md).

## Активные записи v0.25

Кнопка **«Записи: N»** открывает все текущие записи, включая скрытые поиском. Можно перейти к пульту, завершить одну запись или сохранить все с подтверждением. Панель показывает время, путь файла и состояние сохранения. [Инструкция v0.25](CHANGELOG_v0.25_RU.md).

## Проверка места v0.26

Перед записью проверяется выбранный диск: ниже 256 МиБ запись не начинается, ниже 1 ГиБ требуется подтверждение предупреждения. В панели записей отображается свободный объём при запуске; место не резервируется. [Инструкция v0.26](CHANGELOG_v0.26_RU.md).

## Защита экрана v0.27

Настройка **«Не выключать экран при работающем сервере»** сохраняется локально. Программа удерживает запрос на блокировку автоматического сна экрана только во время работы сервера и снимает его при остановке или выходе. Схемы питания Windows не меняются. [Инструкция v0.27](CHANGELOG_v0.27_RU.md).

## Перенос кода v0.28

Windows сохраняет новый VPN-код в файл **`.usc`**, Android загружает его кнопкой **«Загрузить код из файла»** через системный диалог. Камера не требуется. Файл содержит секреты подключения: не публикуйте его и передавайте только нужному оператору. Импорт не запускает VPN автоматически. [Инструкция v0.28](CHANGELOG_v0.28_RU.md).

## Очистка подключения v0.29

Android позволяет **удалить сохранённое подключение** после подтверждения, когда трансляция и VPN остановлены. Удаляются локальный шифротекст и ключ Android Keystore; код на Windows остаётся действующим до отдельного отзыва. Файлы `.usc` и буфер обмена не очищаются. [Инструкция v0.29](CHANGELOG_v0.29_RU.md).

## Защита записей v0.30

При смене комнаты или переходе на общую видеостену с активными записями требуется подтверждение. Отмена сохраняет текущий просмотр и запись. Повторный выбор уже открытой видеостены больше не пересоздаёт соединения и не завершает записи. [Инструкция v0.30](CHANGELOG_v0.30_RU.md).

## Завершение записи v0.31

Исправлена блокировка кнопок после сохранения или ошибки видеозаписи: состояние рекордера завершается до обновления интерфейса. Пауза приёма и новая запись снова доступны без смены раскладки; счётчик скрытых записей обновляется сразу. [Подробности v0.31](CHANGELOG_v0.31_RU.md).

## Горячие клавиши v0.32

Клавиши **1–9** открывают пульт крупно в текущем порядке с учётом поиска; **Escape** возвращает сетку. Первые девять результатов отмечены номерами. Ввод текста, открытые диалоги и полноэкранный режим блокируют горячие клавиши. Записи продолжаются. [Инструкция v0.32](CHANGELOG_v0.32_RU.md).

## Сводка потоков v0.33

Видеостена показывает счётчики состояний и суммарный свежий битрейт входящего видео, включая скрытые записи. Устаревшие данные исключаются; доля измеренных потоков показана отдельно. Это не общий сетевой трафик Windows. [Инструкция v0.33](CHANGELOG_v0.33_RU.md).

## Названия комнат v0.34

Кнопка **«Переименовать»** меняет название выбранной комнаты без остановки трансляций, замены ключей или потери сохранённого порядка плиток. Подписи и поиск обновляются; записи продолжаются. [Инструкция v0.34](CHANGELOG_v0.34_RU.md).

## Имена пультов v0.35

Кнопка **«Переименовать»** в строке действующего операторского ключа меняет имя без перевыпуска кода и остановки эфира. Подписи и поиск используют актуальное локальное имя; текущие записи продолжаются. [Инструкция v0.35](CHANGELOG_v0.35_RU.md).

## Избранные пульты v0.36

Звёздочка на плитке сохраняет пульт в избранное. Фильтр **«Только избранные»** сочетается с поиском; скрытые записи продолжаются. Отметки восстанавливаются после перезапуска и переподключения, порядок не меняется. [Инструкция v0.36](CHANGELOG_v0.36_RU.md).

## Буфер кода v0.37

Код, скопированный кнопкой, очищается через 60 секунд или при штатном выходе, если текущий текст буфера всё ещё совпадает с ним. Другой скопированный текст сохраняется. История буфера Windows и файлы не удаляются. [Подробности v0.37](CHANGELOG_v0.37_RU.md).

## Выбор файла записи v0.38

Штатное закрытие окна теперь дожидается результата выбора файла записи и закрытия поздно созданного файла. Если остановка уже запрошена, запись не запускается. Отмена и ошибка диалога освобождают ожидание. [Подробности v0.38](CHANGELOG_v0.38_RU.md).

## Ошибки остановки записи v0.39

Исключение браузерного рекордера или ошибка освобождения трека больше не пропускают завершение файла и не оставляют кнопки занятыми. Программа сообщает об ошибке и возможном частичном видео; ложный успех не показывается. [Подробности v0.39](CHANGELOG_v0.39_RU.md).

## Архив v0.40

Записи можно сортировать по дате, имени пульта и размеру. Фильтр показывает все, доступные или недоступные файлы и работает вместе с поиском. Изменение параметров не прерывает воспроизведение и трансляции. После перемещения файлов нажмите «Обновить». [Изменения v0.40](CHANGELOG_v0.40_RU.md).

## Звуковой сигнал v0.41

В панели поиска пультов включите «Сигнал зависания» и нажмите «Проверить звук». Если ранее обновлявшееся видео около четырёх секунд не присылает новых кадров, программа подаст короткий сигнал. Интервал между сигналами — минимум десять секунд; повтор для того же зависания отсутствует. Ручная пауза не вызывает сигнал. Функция выключена по умолчанию и действует на текущий сеанс сервера. Звук пульта не передаётся и не записывается. Отсутствие кадров также возможно при неподвижном изображении; это не доказательство обрыва сети. [Подробности v0.41](CHANGELOG_v0.41_RU.md).

## Названия и заметки записей v0.42

В «Архиве записей» нажмите «Название / заметка». Можно изменить название и записать, например, «02:15 — проверка связи». Поиск учитывает заметки. Данные сохраняются локально, повторный импорт того же файла сохраняет их. Видео, его путь и дата не меняются; открытое воспроизведение продолжается. [Изменения v0.42](CHANGELOG_v0.42_RU.md).

## Общий снимок видеостены v0.43

Кнопка «Снимок стены» сохраняет до 16 видимых пультов в один PNG: изображения, названия, состояния и время Windows-ПК. Учитываются поиск, избранное, увеличение и порядок сетки. Видео вписывается в ячейки 640×360 без обрезки; исходное разрешение одного пульта сохраняется прежней кнопкой «Кадр». Состояния паузы и отсутствия новых кадров подписаны. Кадры разных источников не синхронизированы. [Инструкция v0.43](CHANGELOG_v0.43_RU.md).

## Таймеры наблюдения v0.44

Под каждым потоком показаны «В просмотре» (с первого кадра, включая паузы) и «Приём ≈» (оценка времени разрешённого приёма). Ручная пауза и скрытие без записи останавливают второй счётчик; скрытая запись продолжает его. Длинные пропуски измерений не засчитываются в приём. Новый видеотрек или смена просмотра сбрасывают счётчики. Это локальное время наблюдения, а не длительность полёта или запись WebM. [Инструкция v0.44](CHANGELOG_v0.44_RU.md).

## Перенесённые видеозаписи v0.45

Если видео перенесено и стало недоступно, нажмите «Обновить» в архиве, затем «Найти файл» у нужной записи. Укажите тот же WebM в новой папке: название, заметка, дата и ID сохранятся, просмотр снова станет доступен. Видео не копируется и не перемещается программой. Выбор файла отменяется без изменения индекса; файл другой записи отклоняется. [Инструкция v0.45](CHANGELOG_v0.45_RU.md).

## Отметки важных моментов v0.46

При просмотре записи нажмите «Отметить момент» и допишите описание к подставленному таймкоду. Время берётся в момент нажатия кнопки. Таймкод в начале строки заметки становится кнопкой перехода к нужному месту; работают и прежние записи вида «02:15 — событие». Отметки участвуют в поиске, сохраняются локально и не меняют видеофайл. [Инструкция v0.46](CHANGELOG_v0.46_RU.md).

## Исправление создания комнаты v0.47

Встроенная форма заменяет неподдерживаемый Electron prompt при создании комнаты, выпуске ключа и переименовании. [Исправление v0.47](CHANGELOG_v0.47_RU.md).
