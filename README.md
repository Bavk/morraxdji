# Universal Stream Control

Windows-приложение (сервер + просмотр) и Android APK для трансляции экрана через WireGuard.

⚠️ Прототип. Сборки EXE/APK и работа с реальными пультами ещё требуют проверки.

CI: GitHub Actions проверяет сборку Windows и Android, после загрузки исходников в корень репозитория.

**Не загружайте реальные VPN-ключи, приватные конфигурации и операторские коды в публичный репозиторий.**
