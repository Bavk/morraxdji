# Windows v0.47 — исправление ввода названий

Создание комнаты, выпуск ключа, переименование комнаты и пульта используют встроенную форму вместо неподдерживаемого Electron window.prompt(). Форма поддерживает Enter, отмену, фокус поля и проверку длины (80 символов для комнаты, 60 для оператора). Названия отображаются как обычный текст.

Регрессионная проверка Electron открывает настоящую форму создания комнаты, отменяет её, создаёт комнату через API и проверяет появление в списке. Проверки выпуска ключа и переименования также используют настоящую форму вместо подмены window.prompt. Существующие функции сохранены. Пользовательское работающее приложение не закрывается автоматически.
