# Windows v0.50.1 — исправление упаковки сервера

В v0.50 список `extraResources` содержал только ранее известные серверные файлы и пропустил новую зависимость `settings.mjs`. Исходники и тесты API работали, но установленный EXE не запускал сервер с `ERR_MODULE_NOT_FOUND`.

Упаковка теперь включает серверные `.mjs`, исключая тесты. Проверка исходников рекурсивно обходит относительные импорты, а проверка установочного пакета сверяет каждый файл с исходниками и запускает API непосредственно из `win-unpacked/resources/server`. Она проверяет создание комнаты/оператора, сохранение настроек и выдачу сеанса. Эти операции не используют профиль пользователя и не требуют Docker.

Добавлены три регрессионных теста: отсутствующий `settings.mjs`, будущие транзитивные зависимости/циклы и несовпадение упакованного файла с исходником. Комнаты, ключи, VPN и данные пользователя не изменяются. Android остаётся v0.33.
