# Windows v0.27 — защита просмотра от автоматического сна

Настройка «Не выключать экран при работающем сервере» доступна на стартовом экране и в боковой панели просмотра. По умолчанию она включена. Выбор сохраняется локально и действует при следующем запуске приложения.

После успешного запуска сервера программа запрашивает у Windows блокировку автоматического сна экрана через встроенный API Electron. Статус под переключателем показывает, активна ли блокировка. Её можно отключить или включить во время трансляций без переподключения комнат и остановки записей.

При остановке сервера или штатном выходе программа снимает свою блокировку. Пока сервер остановлен, включённая настройка сама по себе не удерживает экран. Схемы питания Windows, таймеры монитора и параметры системы не изменяются. При завершении процесса его запрос перестаёт действовать.

Это защита от автоматического отключения экрана во время работы сервера, а не запрет пользователю выключить ПК, вручную усыпить его или закрыть крышку ноутбука. Политики Windows и ограничения оборудования могут влиять на поведение. Если API недоступен, программа показывает ошибку, продолжая трансляции.

Повреждённая настройка питания вызывает уведомление и включение значения по умолчанию. Ошибка сохранения настройки не выдаётся за успешное сохранение. Локальный файл содержит только логическое значение и исключён из Git. Пользовательские VPN-ключи и профили не затрагиваются.

Для небольших окон боковая панель получила прокрутку, чтобы настройка питания и кнопка остановки сервера оставались доступны. Исходники и прежние функции сохранены. Docker и WSL2 не требуются. Android APK v0.15 со встроенным WireGuard остаётся совместимым.

## Проверки

131 Node-тест. Новые проверки охватывают запуск и снятие блокировки без дублирования запросов, переключение во время работы сервера, сохранение настройки, остановленный сервер, ошибки API, повреждённый файл и ошибку записи.

В Electron проверяются изменение настройки на стартовом экране без запуска блокировки, настоящий powerSaveBlocker при работающем тестовом сервере, отключение и включение через интерфейс при двух видеопотоках, сохранение состояния после перезагрузки интерфейса и снятие запроса при завершении теста. Прежние сценарии видеостены и записи также выполняются.

Тесты подтверждают регистрацию и снятие запроса Electron, но не ожидание реального аппаратного сна монитора. Источники синтетические; реальные пульты, VPN и длительная нагрузка требуют испытаний на оборудовании.
