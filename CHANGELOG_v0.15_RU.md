# Universal Stream Control v0.15 — 22.10.2026

## Основные изменения

1. **Android-сетевая политика.** Ранее `usesCleartextTraffic=true` действовал на весь APK. Теперь release-профиль разрешает HTTP только к Windows VPN-адресу `10.77.0.1`, а произвольные HTTP-адреса LAN остаются доступны лишь в debug-сборке. Передача по WireGuard шифруется самим VPN; это ограничение предохраняет от случайного обращения к открытым HTTP-серверам вне туннеля.
2. **GitHub Actions.** Windows-установщик и Android APK получают `SHA256SUMS.txt` для проверки целостности скачанных файлов. В Android-сборку добавлен стек ошибок Gradle при падении.
3. **Зависимости Electron.** Если в репозитории уже есть `windows/package-lock.json`, CI использует `npm ci`. Без lock-файла первая сборка запускает `npm install`. Рекомендуется после успешной сборки добавить сгенерированный lock-файл в репозиторий, чтобы последующие сборки были воспроизводимее.
4. **Проверка публикации.** Добавлен `scripts/repo-safety.mjs` и корневой `.gitignore`, уменьшающие риск случайной отправки реальных VPN-секретов и файлов запущенных сервисов в GitHub.
5. **Первая сборка.** Добавлен полный русскоязычный `GITHUB_START_RU.md` для GitHub Desktop и GitHub Actions с путями итоговых EXE/APK, проверкой SHA256 и разбором ошибок.

## Что подтверждено

- 63/63 автономных Node.js-теста, проверки структуры проекта, сетевой политики Android и отсутствия файлов известных форматов секретов.
- 7/7 автономных тестов Kotlin StreamProfile (исполнены JVM-компилятором, **не сборкой Android APK**).
- Синтаксис JavaScript и Android XML; корректность структуры архивного файла.

## Не подтверждено

- Первый прогон Actions на GitHub; компиляция Electron, Gradle Android, установщики EXE/APK.
- Работа Wi-Fi/4G/VPN, захват экрана пультов и работа LiveKit на Windows.
- Возможность использовать APK на каждом пульте (зависит от производителя и ограничений Android).
