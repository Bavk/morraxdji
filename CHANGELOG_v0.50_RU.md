# Windows v0.50 / Android v0.33 — настройки комнат и операторов

## Простой интерфейс

По умолчанию включён простой вид: основные действия просмотра, подключение пульта, архив и настройки доступны сразу. Техническое обслуживание собрано в «Инструменты сервера», порядок пультов, снимок стены, проверка видео и отдельные опасные операции доступны в полном виде. Кнопка «Все инструменты» / «Простой интерфейс» переключает вид; выбор запоминается на ПК. Старые функции сохранены. Панель «Операторы и доступ» можно свернуть. В VPN-режиме не показывается ненужный выбор LAN-адреса.

## Настройки оператора

Кнопка «Настройки» открывает карточку, в том числе для оператора, назначенного из другой комнаты:

- Имя, команда/группа, модель пульта, личные заметки администратора.
- Временная приостановка и повторное включение без замены кода и VPN-пира.
- Срок доступа по местному времени; пустое поле означает бессрочный доступ.
- Предпочтительная комната первой в списке Android; она должна входить в разрешённые. При снятии назначения предпочтение очищается.
- Профиль качества: автоматический, экономия, стандарт или детали. Профиль оператора имеет приоритет над профилем комнаты.

Доступные комнаты по-прежнему выбираются кнопкой «Комнаты: N». В списке работают поиск по имени/команде/модели и фильтры: в эфире, подключён, не в сети, приостановлен, срок истёк, отозван. Необратимый отзыв ключа находится в полном интерфейсе; для временного отключения используется карточка.

Сервер запрещает выдачу токена при приостановке или истечении срока. При ручном отключении он сразу пытается завершить сеансы во всех назначенных комнатах. Автоматическая проверка активных сеансов выполняется каждые 30 секунд; неудачные отключения повторяются. Срок нового JWT ограничен сроком доступа. Обычное редактирование имени/заметок/профиля не перезапускает трансляцию. Заметки, команда и модель не передаются Android через API сеанса.

## Настройки комнаты

Карточка «Настройки комнаты»: имя, описание, группа, цвет, приём трансляций, лимит назначенных операторов, порядок в списке и профиль качества. Лимит учитывает все неотозванные ключи с доступом к комнате, включая выданные из других комнат, приостановленные и просроченные. Ноль означает отсутствие дополнительного лимита. Уменьшить лимит ниже текущего числа назначений нельзя. При закрытии приёма действующие операторы отключаются, комната исчезает из выбора Android; записи, ключи и просмотр Windows сохраняются. Повторное открытие возвращает доступ с прежними кодами.

## Android

APK v0.33 применяет профиль, полученный при выдаче сеанса: оператор → комната → сохранённая настройка пульта. Изменение действует при следующем начале трансляции. Старые APK продолжают подключаться, но для применения профиля с Windows нужен v0.33. Постоянная подпись, встроенный WireGuard/WSS и зашифрованное сохранение кода сохранены.

## Совместимость и проверки

Старые комнаты и операторы получают прежнее поведение по умолчанию: приём открыт, доступ включён, срок бессрочный, лимит не задан, профиль выбирается пультом. Исходники и существующие функции сохранены. Новые настройки записываются в локальную базу; при ошибке записи изменения в памяти откатываются до попытки отключения.

222 Node-теста, включая запрет доступа, истечение срока, восстановление после перезапуска, закрытие комнаты, ограничения назначений, наследование качества, отсутствие утечки заметок и откат при ошибке записи. Проверка Electron охватывает карточки и сохранение настроек, поиск, фильтры, простой/полный вид и прежние сценарии двух видеопотоков с записями. В APK добавлены проверки выбора профиля. Работа новых настроек на физическом пульте отдельно не проверялась; результаты компиляции и ссылки на артефакты публикуются после завершения Actions.
