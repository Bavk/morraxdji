# Windows v0.18 — запись видео с ФПВ-пультов

На каждой плитке в комнате и общей видеостене появилась кнопка «● Запись». Нажмите её, выберите новый файл .webm, дождитесь красного индикатора и таймера. Нажатие красной кнопки завершает запись и показывает путь сохранённого файла. Можно одновременно записывать до четырёх потоков, каждый в отдельный файл.

Записывается только принимаемое видео, без микрофона и звука. Экран целиком сохраняется без наложения кнопок, статистики и предупреждений интерфейса Windows. Это WebM с повторным кодированием видео, а не копия исходного сжатого потока; запись создаёт дополнительную нагрузку на Windows-ПК. По умолчанию выбирается VP8 с целевым битрейтом 2.5 Мбит/с. Масштабирование плитки не меняет размер записываемого кадра.

Скрытие записываемой плитки при увеличении другого потока не останавливает её приём. При смене комнаты, переходе в другой режим просмотра или отключении источника запись завершается. После переподключения новый файл нужно начать вручную. Обычное закрытие окна дожидается последнего фрагмента записи.

Существующие файлы не перезаписываются: выберите новое имя. При недостатке места на диске или переполнении очереди запись останавливается с сообщением об ошибке; уже записанный файл может быть частичным. При принудительном завершении процесса или отключении питания сохранность последнего фрагмента не гарантируется.

Запись выполняется на диск последовательно, фрагментами. Очередь ограничена 16 МБ на поток. Операции записи привязаны к окну, открывшему файл; путь выбирается в системном диалоге, а не передаётся из страницы для произвольной записи на диск. Реальные VPN-ключи и коды подключения в файл видео не добавляются.

## Проверки

86 Node-тестов, включая порядок фрагментов и финального фрагмента, права владельца записи, отказ перезаписи файла, лимиты очереди/числа сеансов, ошибки диска, отмену выбора файла и отключение источника во время выбора.

В настоящем Electron с нативным LiveKit проверены две одновременно записываемые трансляции, продолжение записи скрытой плитки, ручная остановка, завершение при отключении источника и закрытии окна. Каждый из трёх полученных WebM-файлов повторно открыт в Chromium, успешно декодирует видеокадры и не содержит аудиотреков. Прежние проверки видеостены и контроля кадров сохранены.

Android APK v0.15 совместим и не требует переустановки. Docker/WSL2 не нужны. Физические пульты, длительные записи и предельная нагрузка требуют испытания на пользовательском оборудовании.
