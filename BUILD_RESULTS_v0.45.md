Оба файла скачаны и сверены с SHA256SUMS.txt. В APK подтверждены libwg-go.so для arm64-v8a, armeabi-v7a, x86 и x86_64. Журнал Android содержит testDebugUnitTest и BUILD SUCCESSFUL. Android-код остался версии 0.29.0; APK на пульт не устанавливался.

Локально и в GitHub прошли 196 модульных тестов, проверки структуры исходников и preflight репозитория. Новые шесть тестов охватывают перенос видео с сохранением ID/названия/заметки/даты/байтов, повторное открытие архива и воспроизведение по прежнему ID, отказ при неверном/недоступном файле, конфликт с другой записью и конкурентный конфликт, одновременную правку заметки, отсутствие восстановления удалённой записи и сохранность индекса/видео при ошибке записи индекса.

Локально прошли build:ui, smoke:ui и smoke:wall. Windows Actions содержит USC_WALL_SMOKE_PASS с переносом синтетического WebM внутри временной папки, появлением «Найти файл» и блокировкой просмотра, отменой выбора, восстановлением ссылки и метаданных, неизменностью файла и повторным декодированием через прежний usc-recording ID. Системный выбор файла подменён тестовым. Подписи и расположение кнопки визуально проверены на снимке Electron. Прежние сценарии видеостены, записи, архива, заметок, общего PNG, сигналов и таймеров сохранены.

В Windows smoke используется сравнение канонических путей временной папки: оно учитывает альтернативное представление пути на runner и сохраняет проверку, что тестовый перенос не выходит за пределы этой папки. Окончательный CI прошёл после этого исправления теста.

EXE установлен при закрытом приложении; код установщика 0. В установленном app.asar проверены версия 0.45.0, интерфейс восстановления ссылки, IPC/обработчик relink, прежние модули и встроенный LiveKit. Пользовательское приложение принудительно не закрывалось.

Функция меняет только путь в локальном индексе. Выбранный файл проверяется по доступности чтения, расширению и заголовку; содержимое не сравнивается с оригиналом. Пользователь должен выбрать именно перенесённую запись. Если файл уже связан с другой строкой архива, операция отклоняется. Отмена не меняет индекс; если недоступная запись ещё воспроизводилась из буфера, при нажатии «Найти файл» её воспроизведение останавливается.

Использовались синтетические источники и временные тестовые файлы. Реальные пульты, VPN, внешний диск и длительная нагрузка отдельно не испытывались. Пользовательские VPN-ключи и профили не читались и не публиковались. Docker и WSL2 не требуются; для VPN Windows нужен WireGuard.

EXE без подписи издателя, APK с debug-подписью. Артефакты хранятся 30 дней; для скачивания может потребоваться вход в GitHub.
