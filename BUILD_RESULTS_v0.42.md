# Результаты сборки v0.42

Исходники: `33c332065926b0d32d9fd0e6f374a3ed9112a28b`. [Запуск GitHub Actions](https://github.com/Bavk/morraxdji/actions/runs/39799930965).

- [Windows EXE v0.42.0](https://github.com/Bavk/morraxdji/actions/runs/39799930965/artifacts/12435686212)
- [Android APK v0.29.0 со встроенным WireGuard](https://github.com/Bavk/morraxdji/actions/runs/39799930965/artifacts/12434692883)

EXE: 100577381 байт, SHA256 `95e2b5b3df3a534e93f40495864cd8d4d92f73dfdd620faa6099ff1cf6db992b`.

APK: 73311213 байт, SHA256 `7f0ceec30cf59fb8dc0e4055c083ed789b20a55e58e0d710cc7d27a979a50b53`.

Оба файла скачаны, SHA256 совпали с SHA256SUMS.txt. В APK подтверждены libwg-go.so для arm64-v8a, armeabi-v7a, x86 и x86_64. Журнал Android содержит testDebugUnitTest и BUILD SUCCESSFUL. Android-код остаётся версии 0.29.0, APK на пульт не устанавливался.

Локально и в GitHub прошли 176 модульных тестов; структура исходников и preflight репозитория проверены. Новые проверки охватывают сохранение названия и заметки, повторное открытие архива и импорт, неизменность видеофайла/ID/пути/даты, старые архивы без заметок, недоступные файлы, валидацию и ограничения длины, параллельные изменения, отсутствие восстановления удалённой записи, поиск заметок и защиту индекса от превышения 8 МиБ.

Локально прошли build:ui, smoke:ui и smoke:wall. В окончательном Windows Actions подтверждены USC_ELECTRON_SMOKE_PASS и USC_WALL_SMOKE_PASS с редактированием/отменой названия и заметки, поиском по тексту заметки, отображением HTML-подобного текста как текста и продолжением воспроизведения того же URL без паузы. Прежние сценарии видеостены, записи, архива, PNG, сигналов, питания и управления источниками сохранены. В тесте добавлено ожидание события закрытия формы перед повторным открытием: без него более медленный CI мог обратиться к уже закрывающемуся диалогу. Окончательная сборка проверена после этого исправления.

EXE установлен при закрытом приложении, код установщика 0. В установленном app.asar проверены версия 0.42.0, форма названия/заметки, IPC и обработчик записи метаданных, прежние модули и встроенный LiveKit. Принудительного закрытия пользовательского приложения не было.

На момент отчёта сводный API Actions показывает queued вопреки завершённым журналам и готовым артефактам; агрегированный успешный статус не подтверждён.

Использовались синтетические видеопотоки и временные тестовые файлы. Реальные пульты, VPN и длительная нагрузка отдельно не испытывались. Пользовательские VPN-ключи и профили не читались и не публиковались. Docker и WSL2 не требуются; для VPN Windows нужен WireGuard.

EXE без подписи издателя, APK с debug-подписью. Артефакты хранятся 30 дней; для скачивания может потребоваться вход в GitHub.
