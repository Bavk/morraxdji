# Windows v0.42.0 — названия и заметки к видеозаписям

В архиве у каждой записи появилась кнопка «Название / заметка». В форме можно изменить название (до 300 символов) и добавить заметку (до 2000 символов), например «02:15 — проверка связи». Поиск архива учитывает название и текст заметки. Сортировка по имени использует новое название.

Изменения сохраняются локально в индексе архива. ID, дата, путь, имя и содержимое WebM-файла остаются прежними. Название воспроизводимой записи обновляется без остановки видео. Отмена закрывает форму без сохранения. Недоступным файлам тоже можно добавить заметку о том, где их искать. Повторное добавление того же файла сохраняет пользовательские название и заметку.

Старый формат архива поддерживается: отсутствие заметки считается пустой заметкой. Пустые названия, превышение длины и недопустимые управляющие символы отклоняются в основном процессе. Сохранение последовательно и атомарно; удалённая из списка запись не восстанавливается редактированием. Индекс размером более 8 МиБ отклоняется до замены предыдущего файла. Заметка выводится как обычный текст, а не HTML. Данные хранятся только на этом ПК и не передаются операторам.

Добавлено шесть модульных тестов (всего 176): сохранение и повторное открытие, повторный импорт, неизменность файла/ID/даты/пути, старые архивы, недоступные файлы, проверка входных данных, параллельные операции и поиск заметок, ограничение размера индекса. Electron проверяет отмену, сохранение, поиск, отображение HTML-подобного текста без разметки и продолжение воспроизведения.

Android остаётся совместимой версии 0.29.0. Docker не требуется. Используются синтетические записи; реальные пульты, VPN и длительная нагрузка отдельно не испытывались.
