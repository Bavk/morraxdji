# Windows v0.21 — журнал событий трансляций

Кнопка «Журнал событий» доступна на стартовом экране и в боковой панели просмотра. Журнал сохраняется на этом компьютере и доступен после перезапуска, даже когда сервер остановлен.

Сохраняются время Windows, имя источника и тип события: начало просмотра потока, отключение ранее наблюдавшегося пульта от комнаты, отсутствие новых кадров и их восстановление, соединение с комнатой и переподключение. Переход между комнатами по команде пользователя не выдаётся за отключение пульта. Повторные одинаковые замеры состояния кадров не создают новые строки; скрытая плитка не считается потерянным потоком.

Журнал описывает наблюдения открытого просмотра, а не круглосуточную историю Android. Неподвижный экран или пауза захвата могут вызвать событие отсутствия кадров. Имена и время относятся к данным, полученным Windows; это не измерение сквозной задержки.

Поиск работает по имени, типу события и дате; результаты разбиты на страницы по 50 строк. Кнопка «Обновить» загружает последние события. Экспорт JSON сохраняет весь текущий журнал (до 2000 событий), независимо от фильтра, в новый файл через системный диалог. Имена источников входят в экспорт. Существующие файлы не перезаписываются.

История ограничена последними 2000 событиями. Ключи VPN, URL подключения, коды операторов, токены и сырые сообщения ошибок в структуру событий не передаются. Из имён удаляются известные форматы кодов и ключей. Локальный файл журнала исключён из Git; он не отправляется на GitHub. При ошибке диска трансляции продолжаются, программа показывает уведомление. Повреждённый журнал автоматически не перезаписывается.

Сохранены видеостена, статистика, запись WebM, архив и PNG-снимки. Docker не требуется. Android APK v0.15 со встроенным WireGuard остаётся совместимым.

## Проверки

112 Node-тестов. Новые проверки охватывают сохранение и повторное чтение, экспорт, ограничение истории, повреждённый файл, ошибки диска, разрешённые типы событий, скрытие ключей в именах, поиск и переходы состояния кадров.

В Electron с нативным LiveKit проверены два синтетических видеопотока, единственное событие остановки/восстановления кадров, событие отключения пульта, поиск и экспорт через интерфейс, повторное чтение истории и сохранение работающей трансляции при открытом журнале. Прежние сценарии записи, архива и снимков также выполняются. Проверен журнал на стартовом экране без работающего сервера.

Реальные пульты, VPN и длительная нагрузка требуют испытаний на оборудовании.
