## VPN

Настроены отдельный WireGuard-интерфейс, HTTPS через Caddy и нативный Node-сервис регистрации. Windows остаётся видеосервером и зрителем. На пульте работает WireGuard внутри APK; новые коды используют WSS по TCP 443. Прямой UDP в проверяемой сети был нестабилен, поэтому успешное испытание выполнено через WSS. Причина блокировки прямого UDP достоверно не установлена. Существовавший ранее VPN не заменялся. Для Windows указан MTU 1280, учётные данные управления защищены DPAPI. Временный тестовый UDP-порт удалён.

Реальные адреса VPS, пароли, приватные ключи, коды подключения и транспортные секреты в этот отчёт и репозиторий не включены.

## Ограничения

EXE без подписи издателя; APK подписан постоянным тестовым сертификатом. Для Windows нужен установленный WireGuard. Если WSS-транспорт разрывается, трансляцию нужно запустить заново; бесшовное восстановление транспорта не реализовано. Длительная нагрузка на нескольких физических пультах разных производителей пока не проверена; два одновременных потока проверены в CI, физический пульт использовался один.

## Использование

В исходной комнате оператора нажмите «Комнаты: N» и отметьте разрешённые комнаты. На Android выбор предлагается при запуске сеанса, если комнат несколько. Кнопка «Настройки просмотра» задаёт порог отсутствия кадров, интервал звуковых сигналов и видимость статистики. Настройки сохраняются на ПК. Существующие функции комнат, ключей, записей и видеостены сохранены.
