# v0.14 — Проверяемость сборки и совместимость разных форматов экрана

- Добавлен настоящий smoke-тест Electron: открывает собранный интерфейс, проверяет загрузку preload IPC и наличие стартовой формы. Используется в GitHub Actions до упаковки EXE. **Его успех пока не подтверждён**, так как локально не удалось установить Electron/Vite из npm.
- GitHub Actions проверяет наличие серверных модулей в `win-unpacked/resources/server` помимо заголовка EXE.
- Android VideoCaptureParameter теперь устанавливает `adaptOutputToDimensions=false`, чтобы не запрашивать обрезку экрана пульта под фиксированное соотношение сторон. Эффект требует проверки на устройствах.
- Из установщика Windows исключены серверные тестовые `.mjs`: включаются только 5 файлов API, необходимых для работы.
- Обновлены номера версий Windows и Android и автономная проверка структуры исходников.
- Подготовлена процедура первого испытания LAN → VPN, с контрольной таблицей результатов.
- Сетевой протокол `USCV1` и формат базы ключей сохранены.

## Что протестировано здесь

- Node.js-тесты сервера, Windows-модулей, VPN-ретранслятора.
- Проверка исходного кода (включая наличие CI smoke и серверных ресурсов).
- JS-синтаксис и Android XML.
- **Не выполнено:** сборка Vite/Electron EXE, сборка Gradle APK, реальный Electron smoke, работа VPN и видеопередача на устройствах. Причина отсутствия EXE в локальной среде: DNS недоступен для registry.npmjs.org, Docker/Android SDK и зависимости не установлены.
