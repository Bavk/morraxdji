# Windows v0.45.0 — восстановление ссылок на перенесённые записи

Если файл недоступен, в архиве появляется кнопка «Найти файл». Нажмите «Обновить», если видео недавно перенесли, затем укажите тот же WebM через системный диалог. Новый путь сохраняется в существующей записи: ID, название, заметка и дата остаются прежними. Размер берётся из выбранного файла. Кнопки воспроизведения и показа в папке становятся доступными после успешного обновления.

Меняется только ссылка в локальном индексе. Видео не перемещается, не копируется, не удаляется и не перезаписывается. Отмена диалога оставляет индекс без изменений. Если недоступная запись ещё воспроизводилась из буфера, её воспроизведение останавливается перед выбором файла; другие записи и прямые трансляции продолжаются. После восстановления нажмите «Смотреть».

Программа проверяет существование файла, расширение WebM, возможность чтения и заголовок EBML. Это не сравнение содержимого с оригиналом: выберите именно перенесённое видео. Файл, уже связанный с другой записью архива, отклоняется без объединения названий и заметок. Сохранение последовательно и атомарно; параллельные изменения заметок сохраняются, удалённая запись не восстанавливается. Повторное открытие архива использует новый путь.

Добавлено шесть модульных тестов (всего 196): перенос и сохранение метаданных/байтов, воспроизведение с тем же ID, неверный или недоступный файл, конфликт с другой записью и параллельный конфликт, сохранение одновременных заметок, отсутствие восстановления удалённой записи и неизменность индекса/видео при ошибке сохранения.

Electron проверяет перенос синтетического WebM внутри временной тестовой папки, недоступность кнопки просмотра, появление «Найти файл», отмену, восстановление пути и метаданных, неизменность видео и повторное воспроизведение через тот же ID. Системный выбор файла подменён тестовым выбором, пользовательские файлы не затрагивались.

Android остаётся совместимой версии 0.29.0. Docker не требуется. Реальные пульты, VPN, внешний диск и длительная нагрузка отдельно не испытывались.
