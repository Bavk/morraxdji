# Windows v0.48 / Android v0.31 — доступ к комнатам, настройки и сохранение подключения

## Оператор и комнаты

В исходной комнате у каждого активного ключа есть кнопка «Комнаты: N». Администратор отмечает от 1 до 100 доступных комнат. Оператор на Android при запуске выбирает одну из разрешённых комнат; единственная комната выбирается автоматически. Сервер проверяет разрешения при каждой выдаче токена, а токен ограничен выбранной комнатой и передачей экрана без подписки на чужие видео. Старые ключи по умолчанию имеют доступ только к своей комнате, повторно выпускать их не требуется. Список разрешений и названия сохраняются в локальной базе Windows. Доступ к другой комнате не создаёт новый ключ или новый VPN-пир.

В выбранной комнате показываются также операторы, которым доступ назначен из другой комнаты. Переименование и отзыв ключа остаются в исходной комнате. При снятии доступа активный сеанс в исключённой комнате отключается; периодическая проверка повторяет отключение и защищает от ещё действующих старых токенов. При отзыве ключа отключаются сеансы во всех комнатах. Удаление исходной комнаты отзывает её ключи, в том числе доступ к другим комнатам. Поэтому перед удалением учитывайте зависимость операторов от исходной комнаты. Удалённая целевая комната исчезает из доступных.

## Настройки

Кнопка «Настройки просмотра» доступна на старте и в панели сервера. Порог отсутствия новых кадров: 2/4/8/15 секунд; минимальный интервал звуковых сигналов: 10/30/60 секунд; техническую статистику можно скрыть. Изменения применяются к существующим потокам без переподключения и остановки записи, сохраняются на этом ПК. Кнопка «По умолчанию» заполняет стандартные значения, применяются после сохранения. Сам звуковой сигнал по-прежнему включается вручную на текущий сеанс. Неподвижный экран тоже может давать отсутствие новых кадров.

## APK

USCV1 и LAN-ключ STRM сохраняются после успешного подключения зашифрованно через Android Keystore; запись настроек подтверждается commit. Адрес LAN и профиль качества сохраняются отдельно. Перезапуск приложения не должен требовать повторного ввода кода. Явная кнопка удаления подключения остаётся. Выбор комнаты появляется при начале нового сеанса, а не переключает активную трансляцию. При отмене выбора сеанс/VPN останавливается. Для старых Windows, где отсутствует API списка комнат, предусмотрен возврат к комнате ключа.

В GitHub Actions настроена постоянная тестовая подпись через закрытый Secret USC_DEBUG_KEYSTORE_B64; ключ не входит в репозиторий и артефакты. Переход со старого APK со случайной debug-подписью потребует однократной переустановки; следующие сборки с постоянной подписью обновляются поверх с сохранением данных. Это тестовая подпись, а не производственный канал обновления.

## VPN

Приложение использует отдельный WireGuard-ретранслятор; Windows остаётся сервером видео и зрителем, VPS маршрутизирует VPN и регистрирует устройства. Существующие туннели не заменяются. HTTPS секрет управления хранится в профиле Windows через DPAPI. Реальные пароли, ключи и конфигурации в репозиторий не включены. Docker не требуется.
