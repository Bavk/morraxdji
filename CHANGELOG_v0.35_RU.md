# Windows v0.35 — переименование пультов без смены кода

В списке операторских ключей выбранной комнаты рядом с действующим пультом появилась кнопка «Переименовать». Новое имя должно содержать от 1 до 60 символов без управляющих символов. Отмена и неизменённое имя ничего не меняют. Отозванный ключ нельзя переименовать.

Меняется только имя: идентификатор оператора, секрет подключения, VPN-настройки и состояние ключа сохраняются. Перевыпускать USCV1-код и переподключать Android не требуется. Сервер не отключает участника LiveKit. При ошибке сохранения возвращается прежнее имя; новое имя сохраняется после перезапуска сервера.

Windows отображает актуальное имя по стабильному идентификатору оператора, даже если его текущий видеосеанс был подключён со старым именем. Подписи плиток и поиск обновляются в отдельной комнате и общей видеостене. При изменении через другой интерфейс нажмите «Обновить». Синтетические и неизвестные участники продолжают показывать имя из видеосеанса.

Активные записи продолжаются. Их начальные имена, пути файлов, архивные записи и прежние события журнала не переписываются. Новые снимки и записи используют актуальную подпись. Сохранённый порядок плиток не меняется, поскольку привязан к идентификатору. Новое имя также попадёт в токен при следующем подключении оператора.

Windows имеет версию 0.35.0. Android APK v0.29 со встроенным WireGuard совместим и собирается заново без изменения Android-кода. Исходники и прежние функции сохранены. Docker и WSL2 не требуются.

## Проверки

147 Node-тестов. Новые проверки охватывают авторизацию, валидацию имени, неизменность сохранённых данных ключа кроме имени, отсутствие отключения, работу старого кода, новое имя в следующем сеансе, ошибку записи, перезапуск сервера, отсутствующий и отозванный ключ. Дополнительно проверен выбор локального имени только для соответствующего идентификатора и комнаты.

В Electron с нативным LiveKit один из двух синтетических источников подключается по настоящему тестовому операторскому ключу. Проверяются обновление имени в видеостене и поиске без замены видеотреков/сеансов записи, а также переименование через кнопку списка ключей при активной записи. Прежние сценарии сохранены.

Используются синтетические ключи и видеопотоки. Пользовательские VPN-секреты не читаются и не публикуются. Реальные пульты, VPN и длительная нагрузка требуют испытаний на оборудовании.
