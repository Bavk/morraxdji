# Изменения Universal Stream Control v0.9

## Windows и LiveKit

- Новый `windows/compose-config.cjs` для формирования конфигурации LiveKit и Docker Compose без публикации видеопортов на всех сетевых интерфейсах. Раздельные привязки для 127.0.0.1 и выбранного VPN/LAN IPv4. В отличие от v0.8 конфигурация не использует `"7880:7880/tcp"` без host IP.
- Новый `windows/server-recovery.cjs`: обнаружение и завершение проверенного Docker Compose проекта от предыдущего запуска. Не затрагивает локальные комнаты, секреты и WireGuard.
- Кнопка восстановления доступна в стартовом окне Windows после обнаружения контейнера и конфликта портов.
- Добавлена защита от двух параллельных экземпляров Electron и ожидание окончания команды запуска при штатной остановке сервера.
- Диагностика дополнена состоянием оставшегося контейнера.

## Ключи и VPN

- Сбой принудительного отключения участника LiveKit больше не превращает успешную запись `revoked=true` в ошибку API, останавливающую очистку VPN.
- В ответе API сохраняется `mediaDisconnected=false` и предупреждение, когда принудительное завершение медиасеанса не удалось.
- Команда «Проверить отзыв VPN-ключей» повторяет удаление только тех пиров, чьи ключи помечены отозванными локально. Если VPS пока недоступен, запись о пире остаётся для следующей попытки.

## Android

- Добавлена защита MediaProjection от устаревшего системного разрешения после команды «Остановить» или нового сеанса.
- Обновлён номер версии Android до 0.9.0, versionCode 9.

## Автоматические проверки

- **35/35 Node.js unit/integration mock-тестов**: включая новые проверки сетевых привязок, аварийного восстановления и отзыва ключей при недоступном LiveKit/relay.
- Проверки синтаксиса JavaScript, Bash и разбора Android XML прошли.
- Kotlin CLI-компиляция профилей не завершилась в отведённое время. Gradle/Android SDK/Docker Desktop недоступны в этой среде.
- **Не проверено на живых устройствах:** EXE/APK, Docker-публикация IP на Windows, WireGuard через VPS, настоящий экран Android, нагрузка на десятки операторов.
