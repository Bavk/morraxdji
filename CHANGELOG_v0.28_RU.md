# v0.28 — перенос VPN-кода на пульт через файл

В окне выдачи нового операторского кода Windows появилась кнопка «Сохранить VPN-код». Она сохраняет единый код USCV1 в новый файл `.usc` через системный диалог. Код проверяется перед сохранением, существующие файлы не перезаписываются. Для старого LAN-ключа кнопка недоступна. Код по-прежнему можно скопировать в буфер обмена.

В Android APK v0.28 появилась кнопка «Загрузить код из файла .usc». Перенесите файл на пульт доступным способом и выберите его через системный файловый диалог. Камера и широкое разрешение на хранилище не нужны. Читается только выбранный документ, не более 4097 байт; файлы больше 4096 байт отклоняются. Код проверяется существующим валидатором VPN-подключения, включая адрес, ключи и порт.

Импорт только заполняет поле кода. Он не запускает VPN или захват экрана автоматически: нажмите «Начать трансляцию» и подтвердите штатные запросы Android. Во время активного сеанса импорт не применяется. Ошибки чтения и формата показываются без вывода содержимого файла. Выбор качества, прежний ввод кода и встроенный WireGuard сохранены.

Файл `.usc` содержит секрет оператора и приватный ключ VPN. Передавайте его только соответствующему оператору, не публикуйте и удаляйте лишние копии после передачи. Расширение исключено из Git. Файл не шифруется самим форматом, не является QR-кодом и не отправляется программой во внешние сервисы. Выданный код нельзя повторно получить из списка ключей; при утрате выдайте новый и отзовите старый.

Windows и Android имеют версию 0.28.0; Android versionCode увеличен до 28. Старые USCV1-коды совместимы. Исходники и функции прежних версий сохранены. Docker и WSL2 не требуются.

## Проверки

133 Node-теста, включая точное сохранение синтетического кода, запрет перезаписи и отклонение неверных, слишком больших и многострочных данных. В Electron проверяется выдача синтетического кода, сохранение через интерфейс и равенство содержимого файла исходному коду; реальные VPN-секреты не используются. Прежние сценарии двух видеопотоков, записи, поиска, питания, архива и снимков сохранены.

В Android добавлены три JUnit-теста: BOM и перенос строки, проверка формата и передача ошибки валидатора, ограниченное чтение бесконечного потока. Actions теперь выполняет `testDebugUnitTest` перед сборкой APK. Тесты чтения используют синтетические данные и подставной валидатор; штатный Enrollment.parse применяется в приложении. Проверка импорта системным файловым диалогом и VPN на реальном пульте ещё требуется.
